# 玩法设计与平衡说明

## 核心循环

一局从庭院开始，先选择一件起手道具，再进入连续房间。普通房间由多段蝶障遭遇组成，清除每段后获得 P 点、逆势能量和三选一道具。房间完成后开放出口，玩家可以在战斗、商店、疗愈和裂隙之间选择路线，最后挑战异化蝶魁。

战斗的爽点来自短周期决策：

1. 用持续射击和散射快速清场，命中与击杀积累逆势能量。
2. 用 H 弹反把敌方弹幕转成高伤害友方弹，或用 U 倒置切入上沿路线。
3. K 冲刺提供短暂无敌，I 革命在满能量时反转屏幕内弹幕并造成范围伤害。
4. 连击每 5 次额外获得 P 点，击杀回血和波次恢复降低重复失败成本。

## 构筑方向

| 方向 | 主要道具 | 玩法特点 |
| --- | --- | --- |
| 火力 | 御币、量贩型小麻薯、绯红折扇 | 更高伤害、额外射弹和侧向散射，适合持续压制 |
| 机动 | 魔女扫帚、轻身伞、闪避布残片 | 移动、重力和防护时间提升，适合冲刺与倒置穿行 |
| 反制 | 阴阳玉、返月镜、子安贝 | 穿透、弹反强化和减伤，适合贴近弹幕窗口 |
| 续航 | 伊吹瓢、招福铃、蝶心结 | 生命上限、击杀回血和能量获取，适合长线挑战 |

道具以 Resource 保存，数量和上限可在 `resources/items/*.tres` 以及 `scenes/player/player_stats.gd` 调整。每局奖励由种子固定，重开不会通过随机顺序刷出不同结果。

## 当前平衡基线

数值集中在 `resources/balance/爽快模式.tres` 对应的 `RunBalance` 资源中：基础射击伤害 12，射击间隔 0.17 秒，冲刺冷却 0.85 秒，倒置冷却 7 秒，革命伤害 95，普通敌人生命按房间阶梯增加，Boss 基础生命 2600。首次死亡会以 50% 最大生命复活并获得 2.5 秒无敌。

如果试玩中出现“清场太慢”，优先提高 `shot_damage` 或降低 `shot_interval`；如果出现“技能没有决策价值”，优先调整 `energy_per_hit`、`energy_per_kill` 和 `revolution_damage`；如果出现“失败代价仍然过高”，调整 `wave_healing`、`revive_fraction` 或商店治疗价格。

## 房间流程

推荐路线为：

```text
庭院 → 一·蝶迹 → 商店 / 兽道 → 疗愈 → 逆行隙间 → 竹林 → 裂隙前夜 → 最后补给 / 月下息所 → 蝶魁 → 庭院结算
```

每个普通房间的遭遇、波次和触发位置保存在对应的 `regular_level*.tscn` 中，`EncounterDirector` 只负责运行时生成敌人和奖励。倒置秘藏放在普通关卡上沿，鼓励玩家熟悉倒置路线，而不是强制完成。

## 持续游玩动力

`JourneyProfile` 会记录通关次数、尝试次数、最远房间和道具发现。首次胜利后可从庭院再次开始“异变再临”挑战，敌人生命提高 35%。奖励发现记录保存在 `user://journey_v1.cfg`，用于后续扩展解锁、剧情和更高难度。

## Godot 调整入口

- 战斗节奏与奖励：`resources/balance/爽快模式.tres`
- 道具属性与价格：`resources/items/*.tres`
- 敌人波次与路线：`scenes/maps/regular_level*.tscn`
- 遭遇生成与结算：`scripts/combat/encounter_director.gd`
- 三选一界面：`ui/rewards/reward_screen.tscn`
- 旅程记录：`scripts/progression/journey_profile.gd`

所有动态对象仍在运行时实例化，持久结构和可调参数保留在场景与 Resource 中，便于直接在 Godot Inspector 继续迭代。
